# Мини-Реставратор

Cozy 3D симулятор реставратора кукольных домиков для Android. Godot 4.3, вся графика процедурная, внешних ассетов нет.

Вы приводите в порядок старый домик дедушки Яна, и с каждым этапом открывается воспоминание о его семье.

## Что уже есть (первый вертикальный срез)

- Одна комната с окном, розетками и девятью предметами мебели в беспорядке
- **Кисть**: стереть пыль с пола
- **Обои**: 4 узора, оклеить 3 стены
- **Краска**: перекрасить мебель в 6 цветов
- **Мебель**: перетащить и повернуть предметы
- **Свет**: подключить лампы к розеткам, комната погружается в уютный вечер
- **Фото**: свободная камера, эффект макро-размытия, 3 фильтра, сохранение PNG
- **Дневник**: 6 воспоминаний, открываются за этапы
- Управление: тянуть по пустому месту или стене вращает камеру, щипок или кнопки +/- меняют масштаб

## Сборка APK на GitHub (без установки Godot)

1. Создайте репозиторий и загрузите проект:
   ```
   git init
   git add .
   git commit -m "Мини-Реставратор"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/mini-restorer.git
   git push -u origin main
   ```
2. Откройте вкладку **Actions**, workflow **Build Android APK** запустится сам. Можно запустить вручную: *Run workflow*.
3. Через 5-10 минут скачайте APK из **Artifacts** (`mini-restorer-apk`) и установите на телефон. Разрешите установку из неизвестных источников.
4. Тег вида `v0.1.0` прикрепит APK к релизу:
   ```
   git tag v0.1.0 && git push --tags
   ```

APK подписан debug-ключом, этого достаточно для установки и тестов. Для Google Play нужна release-сборка с вашим ключом.

## Локальный запуск

Откройте папку в Godot 4.3 или новее и нажмите F5. На ПК мышь заменяет палец, колесо мыши даёт зум.

## Фото на Android

Игра пытается сохранить снимок в `Pictures/MiniRestorer`, а если система не даёт, то во внутреннюю папку приложения. Путь показывается во всплывающей подсказке.

## Идеи на потом

- Несколько домиков и историй, сохранение состояния комнат
- Звуки (шорох кисти, щелчок выключателя) и тихая музыка
- Мини-инструменты: пинцет для мелочей, шкурка, лак
- Реальные модели мебели вместо примитивов
- Сохранение фото в галерею через плагин MediaStore
